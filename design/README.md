# Design — "Området", Broadsheet night edition

The visual design for area-overview, made in Claude Design (project
"Norwegian Aurora App Design", file `Area Overview Kiosk.dc.html`) and
exported here on 2026-09-05. This directory is the reference the frontend
phases implement; the app's own CSS lives in `src/web/styles/`.

## Files

| File | What it is |
| --- | --- |
| `area-overview-kiosk.dc.html` | The artboard file exactly as exported. Source of truth. Only renders inside Claude Design's runtime. |
| `artboards.html` | The same artboards as a plain HTML page. **Open this one in a browser.** Generated by `export.py`; do not edit by hand. |
| `broadsheet/styles.css` | The Broadsheet design-system tokens and component classes the artboards link. Light-ground original; the app inverts the neutral ramp (see below). |
| `broadsheet/readme.md` | The design system's own guide: direction, colour, type, do/don't. |
| `export.py` | Rebuilds `artboards.html` from the `.dc.html`. |

## What the design says, in one place

- **Ground:** ink `#100f0f`, paper `#f3f2f2` — Broadsheet's neutral ramp
  inverted. No boxes, no dividers; hierarchy is type size and whitespace.
  The only rules are the masthead's 3 px + 1 px pair.
- **Spot colour:** cyan `--color-accent-400` `#62c5ee` is everything
  interactive and the ships; magenta `--color-accent-2-400` `#ff90b1` is
  the rarer second colour — aircraft, the Kp figure, the password field.
  Process yellow `#edbb00` is **warnings only**: stale-data banner, NOAA
  alert, an old camera image, the tide curve's now-line. Never both accents
  in one small component.
- **Type:** Source Serif 4 for everything, headings at weight 600, true
  italic for descriptions and summaries. Small caps labels are 11 px with
  0.14–0.18 em tracking. Numerals are the display: 168 px temperature,
  150 px Kp, 104 px tide level, 96 px point forecast.
- **Touch:** every tap target is ≥ 44 px on the 1024 × 600 panel at scale 1.
- **Images:** camera images take the `.halftone` newsprint dot screen.
- **Icons:** Phosphor, duotone, if any are needed. The artboards use none.

## Light theme

The design is the night edition. The light theme is Broadsheet's own
uninverted tokens (`--color-bg: #f3f2f2`, `--color-text: #201e1d`, accents
at 500) with the same layout — nothing is redesigned for it.
